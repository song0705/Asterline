Asterline @VERSION@
==================

[English: README.txt]

1. 双击“Install Asterline.pkg”。
2. 按照 macOS 标准安装器完成步骤。
3. 打开新的终端窗口并运行：

       ast --help

安装包会将 `ast` 和 `asterline` 都安装到 /usr/local/bin。

仅当 Release notes 明确说明时，此 DMG 才经过 Developer ID 签名和公证。若 macOS 显示
“来自身份不明的开发者”警告，请将该 artifact 视为未签名且未公证；只能在核对该 DMG 旁
发布的 Release 校验和与 GitHub 构建 provenance attestation 后，才使用安全绕过。

# Asterline v0.2.0

Asterline v0.2.0 turns the original multi-agent console into a
conversation-scoped collaboration runtime. This release adds durable runs,
structured brainstorming with automatic private voting, resumable team
conversations, richer native CLI streams, and a model-aware Team editor.

## Highlights

- Added five persistent dispatch modes: `normal`, `review`, `plan`,
  `brainstorm`, and `team`. A mode belongs to its conversation; `/new` starts
  in normal mode and `/resume` restores the selected conversation's mode.
- Rebuilt brainstorm as a complete method rather than a single generation
  round. Participants now run judgment-free seed, build, and stretch waves,
  retain an append-only IdeaSet, submit private ranked ballots, aggregate with
  deterministic Borda scoring, and synthesize a ranked recommendation.
- Added the deployment-local `asterline-brainstorm` Skill. It defines
  extractable idea-card and ballot schemas while allowing each workspace to
  customize its brainstorming method without being overwritten.
- Replaced loose workflow state with conversation-scoped runs. `/runs` exposes
  phases, checklists, owners, timelines, blockers, verification, and suggested
  next actions; `/continue`, `/note`, `/block`, `/verify`, and `/step` provide
  explicit lifecycle control.
- Added `/resume` with a saved-conversation picker. Restoring a conversation
  brings back its transcript, roster, member configuration, native backend
  session IDs, selected mode, and runs.
- Reworked Team selection into visible Agent/model/session lists. Installed
  backend availability, model catalogs, and model-specific reasoning-effort
  levels load automatically when the builder or `/team` opens. `default`
  appears only when no model is discovered.
- Improved backend fidelity. Grok now uses ACP stdio, Agy uses native
  `stream-json` output, and Codex/Claude adapters preserve richer reasoning,
  tools, command output, diffs, failures, and session metadata.
- Improved terminal interaction with copyable chat/header/footer/drawer text,
  prompt history, transcript search, Unicode-safe Team editing, atomic paste,
  clearer run status, and complete English and Chinese command references.
- Expanded approval coverage, verification loops, session persistence, and
  adapter/runtime regression tests.

## Breaking changes

- Legacy roundtable/workflow configuration and UI paths were removed. Update
  `team.json` to use `modes.brainstorm` or `modes.team`; legacy
  `modes.roundtable` is rejected.
- Collaboration modes are selected with `/mode <name>` and the task is entered
  as the next message. Removed one-shot mode commands are not retained as
  aliases.
- A new conversation always starts in `normal` mode. `/resume` is the supported
  way to return to a previous conversation, team state, and mode.
- `default` replaces old `auto` placeholders in model/session presentation.
- `/retry` re-sends the latest user request. Use `/continue` for a blocked or
  failed run.

## 中文摘要

- 新增 `normal`、`review`、`plan`、`brainstorm`、`team` 五种对话级持久模式；
  `/new` 从 normal 开始，`/resume` 恢复所选对话原来的模式。
- Brainstorm 现在完整执行 seed、build、stretch 三类无评判生成波次，再进行私密
  排序投票、确定性 Borda 聚合和排名综合，不再停在一轮想法输出。
- 新增可按部署定制的 `asterline-brainstorm` Skill，以结构化卡片和选票支持稳定
  提取、投票与综合。
- 使用属于当前对话的 Runs 取代松散工作流状态，提供清单、负责人、阻塞、备注、
  验证、恢复和下一步操作。
- `/resume` 通过列表选择历史对话，并一起恢复聊天、Roster、成员配置、原生会话
  ID、模式和 Runs。
- Team 编辑器会自动检测 Agent、模型和模型支持的 effort，并使用列表完成选择；
  只有未发现模型时才显示 `default`。
- Grok 改用 ACP stdio，Agy 改用原生 `stream-json`，并完善 Codex、Claude 的思考、
  工具、命令、diff、失败与会话事件透传。
- 完善终端复制、提示历史、聊天搜索、Unicode 编辑、Runs 状态以及中英文命令文档。
- 不再兼容旧 roundtable/workflow 配置；请迁移到 `modes.brainstorm` 或
  `modes.team`。

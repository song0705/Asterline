# Asterline v1.0.3

[English](v1.0.3.en.md)

> `/new` 后 run 编号从本对话重新计，mode 设置会留下来。Team 默认只用现有队员。
> Codex 工具询问默认自动通过；手动审批是可选开关。

---

## 重点内容：你现在可以

- `/new` 后本对话从 `run-1` 再计，不必重配 reviewer、builder 等 mode 字段。
- `/runs` 列出全部步骤，不再只显示前八步。
- Brainstorm 按设定张数出卡片，多出来的会丢掉。
- Team 模式默认锁定当前名册；Mode 面板可改成自由加人，加人立刻生效、不用审批。
- `/team` 里手动加人会复制当前队员的写入权限，焦点回到名字，不会一按 Enter 就拨到 `plan`。
- Codex 工具询问默认自动通过。需要卡片时用 `--manual-approvals` 或
  `team.json` 的 `"approvals": { "manual": true }`，然后按 `y` / `n`。

---

## 概览

v1.0.3 修的是对话局部的 run 编号、清单通知连发、Agy Write 卡片、取消后 429，
以及「加人要审批 / 新人变成 plan」这类协作摩擦。关键词拦整段 prompt 已去掉；
还需要人点头的只有打开手动审批后的 Codex 工具，以及 Plan 关掉自动执行时的确认。

---

## 升级提醒

`v1.0.2` 已经发布。不要移动或重打旧 tag。Team 默认不再让 `@@team_member` 加人；
要自由加人，在 `/mode` 的 team 字段打开 `allow_add_members`。想恢复工具询问卡片，
加上 `--manual-approvals`。

# Asterline v0.2.2

Asterline v0.2.2 is a cross-platform CI and session-import hotfix for v0.2.1.

## Fixes

- Fixed Claude attach import on filesystems whose modification timestamps have
  coarser precision than the process clock. Newly forked Claude session files
  now use the same two-second clock-skew allowance as transcript rows, so new
  attached messages are not missed on Windows.
- Made the embedded team-skill protocol assertion independent of LF versus
  CRLF checkout line endings.
- Split the Grok oversized-ACP-frame regression into a bounded frame-generation
  phase and a separate five-second teardown phase. This preserves the process
  termination guarantee without failing on slower shared macOS runners before
  the 8 MiB fixture has been produced.
- Added macOS and Windows test jobs directly to the Release workflow. Release
  builds and publication now wait for all three operating-system test gates,
  rather than relying only on the separate branch CI workflow.

## 中文摘要

- Claude attach 导入现在为新 fork 会话文件的修改时间应用两秒时钟容差，避免
  Windows 文件时间精度导致新消息漏导入。
- Team Skill 协议测试兼容 LF 与 CRLF checkout。
- Grok 超大 ACP 帧测试分别限制数据生成时间与错误后进程回收时间，消除 macOS
  共享 runner 上的误超时，同时保留五秒内终止的约束。
- Release workflow 现在必须通过 Linux、macOS、Windows 三个平台测试后才能构建
  和发布产物。

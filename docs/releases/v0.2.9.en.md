# Asterline v0.2.9

[简体中文](v0.2.9.md)

> This release is about using the terminal: a full-screen chat, wheel
> scrolling, drag-select copy, and continuing the last conversation when you
> reopen Asterline. Native sessions are also more honest — Claude tools stay
> ahead of the final reply, Codex keeps streamed text, and Team model catalogs
> can be refreshed with `t` at any time.

---

## Highlights

- Scroll chat with the mouse wheel, recall prompt history with the arrow keys,
  and drag-select to copy. The highlight is a neutral zinc wash, not a bright
  blue bar. Exiting restores the previous terminal.
- Reopening Asterline continues the current conversation. Only `/new` or
  `/clear` starts a fresh session; they are now the same command.
- Claude thinking defaults to an elapsed-time line; press `Ctrl+T` to expand
  it. Tool calls appear before the final reply.
- Press `t` on a member's **model** field in `/team` to re-fetch that backend
  catalog at any time. Startup scans all four installed CLIs instead of waiting
  until you add a member.
- Recognize `Asterline · member` in official Codex / Claude resume lists. After
  a project move, a stale workspace stored in `.asterline/team.json` is corrected
  to the directory you opened.

---

## Overview

v0.2.9 is a maintenance release focused on terminal feel and session
continuity. The main UI uses the alternate screen: header at the top, chat in
the middle, composer at the bottom. The wheel scrolls chat instead of walking
prompt history. Drag-select copies through OSC 52.

Claude's thought stream is collapsed by default. Codex App Server keeps
streamed text when `item/completed` is missing. An `@member` message during a
collaboration run stays a one-to-one route.

There is no database schema migration. Existing team files remain compatible.

---

## New capabilities

### Full-screen chat: scroll, copy, pinned header

The main TUI takes the alternate screen so `cargo run` or `ls` is not mixed
into the conversation. The wheel scrolls chat or an open drawer; arrow keys
still recall prompt history. Drag-select highlights only the covered text with
a zinc background.

### Reopen continues; `/clear` is `/new`

The last selected conversation, roster, and backend sessions come back on
restart. `/new` and `/clear` both reset the conversation and allocate new
backend session IDs. Active members or collaboration runs still reject that
reset.

### Team: scan catalogs at startup, refresh with `t`

Installed CLI catalogs are loaded once at startup and shared by backend and
working directory. Focusing **model** and pressing `t` re-fetches that catalog
whether the previous load succeeded or failed; an in-flight request is not
duplicated.

---

## Interaction changes

- Claude thinking collapses to an elapsed hint; `Ctrl+T` / `Ctrl+O` / `Ctrl+G`
  expand detailed output.
- Codex native threads are labeled `Asterline · <member>` in official resume
  lists.
- During a collaboration run, a message to a single member is a normal
  one-to-one route.
- A streamed reply that only received deltas is not wiped by an empty
  completion event.

---

## Upgrade notes

### Do not reuse the `v0.2.8` tag

`v0.2.8` is already published. This release is `v0.2.9`. Do not move or recreate
the old tag.

### Drag-select uses the application clipboard

Full-screen ownership means the terminal no longer provides native selection.
On mouse-up the text is written with OSC 52. VS Code and a plain terminal use
the same path.

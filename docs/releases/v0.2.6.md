## Highlights

- GNU/Linux Release assets now use a consistent, architecture-visible layout:
  `asterline-v<version>-Linux-arm64` and
  `asterline-v<version>-Linux-x86_64`. Each architecture has a portable archive,
  a Debian/Ubuntu `.deb`, and an RPM `.rpm`.
- The Debian packages are installed, executed, and removed on Debian 12 and
  Ubuntu 24.04. RPM packages are built and tested on Rocky Linux 8, then
  installed, executed, and removed again on Fedora 44.
- All Release assets remain covered by the ordered `SHA256SUMS` file and GitHub
  artifact attestations. The RPM files are Release assets, not a configured DNF
  repository or GPG-signed RPM repository packages.

## 中文摘要

- GNU/Linux 发布资产改为一眼可辨认的命名和成组排列：
  `asterline-v<version>-Linux-arm64` 与
  `asterline-v<version>-Linux-x86_64`。每种架构都有便携 `.tar.gz`、Debian /
  Ubuntu `.deb` 和 RPM `.rpm`。
- `.deb` 包会在 Debian 12、Ubuntu 24.04 上完成安装、执行和卸载验证；RPM 包会先在
  Rocky Linux 8 构建和验证，再在 Fedora 44 上重复安装、执行和卸载验证。
- 所有发布资产仍由固定顺序的 `SHA256SUMS` 和 GitHub artifact attestation 覆盖。RPM
  文件是 Release 附件，不是已配置的 DNF 仓库，也不是 GPG 签名的 RPM 仓库包。

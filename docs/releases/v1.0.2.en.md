# Asterline v1.0.2

[简体中文](v1.0.2.md)

> `/team` now shows each backend's own mode names and pairs the matching
> sandbox underneath. The engine no longer runs a verify command; review
> keeps an optional hint only.

---

## Highlights

- Use each CLI's own mode names in `/team` instead of one shared vocabulary.
- Codex has a single permissions field: `Read Only`, `Ask for approval`,
  `Approve for me`, and `Full Access`, matching `/approvals`.
- Grok offers `default` / `auto` / `plan` / `always-approve`. Always-approve
  turns the sandbox off; the other modes use `workspace`.
- Agy offers `accept-edits` / `plan` / `dangerously-skip-permissions`.
  Only `plan` passes `--sandbox`; `accept-edits` no longer jails the terminal.
- Review mode accepts an optional `reviewer_hint`. There is no `/verify`,
  and passing review no longer runs `cargo test`.

---

## Overview

v1.0.2 is about honest permission display and passthrough, plus removing a
non-generic verify command. Claude still shows only `--permission-mode`.
Grok and Agy do not show a sandbox row, but each mode still sends its matching
sandbox flags. Existing `team.json` files still load; a Codex member that does
not match a preset shows `Custom permissions`.

---

## Upgrade notes

`v1.0.1` is already published. Do not move or retag it. Existing rosters are
not rewritten; change a member in `/team` to pick a new default or preset.

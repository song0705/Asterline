# Asterline v1.0.2

[English](v1.0.2.en.md)

> `/team` 现在显示各后端自己菜单里的名字，并在底下配上对应沙箱。引擎不再
> 跑验证命令；审阅只保留可选提示。

---

## 重点内容：你现在可以

- 在 `/team` 里用各 CLI 自己的模式名，而不是一套共用词。
- Codex 只选一档权限：`Read Only`、`Ask for approval`、`Approve for me`、
  `Full Access`，对应官方 `/approvals` 预设。
- Grok 只选 `default` / `auto` / `plan` / `always-approve`。Always-approve
  会关掉沙箱；其余档用 `workspace`。
- Agy 只选 `accept-edits` / `plan` / `dangerously-skip-permissions`。
  `plan` 才开 `--sandbox`；`accept-edits` 不再误开终端 jail。
- 审阅模式可以写可选的 `reviewer_hint`。没有 `/verify`，也不会在通过后
  自动跑 `cargo test`。

---

## 概览

v1.0.2 修的是权限显示和透传，以及删掉不通用的验证命令。Claude 仍只显示
`--permission-mode`。Grok 和 Agy 的选择菜单里没有 sandbox 一栏，但每档模式
都会带上对应的沙箱参数。旧 `team.json` 继续能读；对不上预设的 Codex 成员
显示 `Custom permissions`。

---

## 升级提醒

`v1.0.1` 已经发布。不要移动或重打旧 tag。现有 roster 不会自动改权限；要
用新默认或新预设，在 `/team` 里拨一下对应成员。

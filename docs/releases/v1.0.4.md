## 重点内容：你现在可以

- 打开仓库先看到中文说明和圆角截图；英文在 `README.en.md`。
- Team 模式里 `@planner` 这类定向消息只发给那个人，不会变成 `team run-N`。不带 `@` 的纯文本才开新 run。
- 模型用 `@@team_member` 只传名字、后端、角色时，套该后端的写入默认。Agy 是 `accept-edits`、沙箱 off。写了 `permission_mode` / `sandbox` 仍按它写的来。
- Agy 在 print 下拒掉一条 shell 时，Plan / Team 继续走，Notice 会写出被拒的命令。
- `/resume` 只在选中对话要出视口时才滚。
- Claude 思考从 thinking 一开始就计时；同一拍结束会显示 `thought`，不再写 `thinking for 0s`。
- Agy 的 `write_to_file` / `replace_file_content` 归到 file changes。流里没有正文时只显示路径，和官方 CLI 一样。

## 概览

v1.0.4 把产品说明改成中文入口，并修了 Team 协作里两处容易误会的默认行为：给 leader 发消息被当成新 run，以及自动加人落成 Agy 的 `plan`。权限拒绝不再掐断整段 Plan。

# Asterline v1.0.3

[简体中文](v1.0.3.md)

> `/new` restarts run numbers in this chat and keeps mode knobs. Team mode
> stays on the current roster by default. Codex tool asks auto-pass unless
> you turn on manual approval.

---

## Highlights

- `/new` starts again at `run-1` in the new chat and keeps reviewer, builder,
  and other mode field settings.
- `/runs` lists every checklist step, not just the first eight.
- Brainstorm emits exactly the configured number of cards; extras are dropped.
- Team mode defaults to the current roster. The Mode panel can allow free add;
  new teammates join immediately, with no `/approve` step.
- Adding a member in `/team` copies the selected member's write permissions
  and focuses the name field, so Enter does not cycle the new member to `plan`.
- Codex tool asks are approved automatically. Turn on the composer card with
  `--manual-approvals` or `"approvals": { "manual": true }` in `team.json`,
  then press `y` or `n`.

---

## Overview

v1.0.3 is about conversation-local run numbers, quieter checklist notices,
Agy Write cards, fewer 429s after cancel, and less friction when adding
teammates. Prompt-keyword gating is gone. The only remaining human holds are
optional Codex tool asks (when manual approval is on) and Plan execute
confirmation when `auto_execute` is off.

---

## Upgrade notes

# Asterline v1.0.4

[简体中文](v1.0.4.md)

> Chinese is the default README. In Team mode, `@member` is a direct
> message, not a new run. Omitted `@@team_member` permissions use write
> defaults, so Agy no longer lands on `plan`.

---

## Highlights

- The repo opens on a Chinese README with rounded screenshots; English is
  `README.en.md`.
- In Team mode, `@planner` and other explicit targets stay one-to-one. They
  do not become `team run-N`. Plain text still starts a new run.
- `@@team_member` with only name, backend, and role takes that backend's
  write defaults. For Agy that is `accept-edits` with sandbox off. Explicit
  `permission_mode` / `sandbox` still win.
- When Agy refuses a shell in print mode, Plan / Team continue. The notice
  names the denied command.
- `/resume` scrolls only when the highlighted chat would leave the viewport.
- Claude thinking starts the clock when thinking begins. A same-tick close
  shows `thought` instead of `thinking for 0s`.
- Agy `write_to_file` / `replace_file_content` land under file changes.
  When the stream has no body, only the path is shown, matching the official
  CLI.
- Crate-level checks are split by topic: `tests/docs.rs`,
  `tests/packaging.rs`, and `tests/release.rs`.
- Release archives ship `README.md` and `README.en.md`. They no longer copy
  the retired root `README.zh-CN.md`.

---

## Overview

v1.0.4 makes Chinese the product README and fixes two Team defaults that
were easy to misread: a message to the leader becoming a new run, and an
auto-added Agy teammate landing in `plan`. A refused command no longer
kills the whole Plan. Crate-level tests and release archives follow the
same Chinese-default README layout.

---

## Upgrade notes

`v1.0.3` is already published. Do not move or retag it. Team mode still
locks the current roster unless you enable `allow_add_members` in `/mode`.

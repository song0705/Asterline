# Asterline v0.2.4

This release hardens local workspace handling, makes long-running teams more
responsive, and adds a safer, more repeatable distribution pipeline.

## Highlights

- Workspace state, generated skills, locks, and imported transcripts now reject
  unsafe symbolic-link and traversal paths instead of following them outside
  the selected workspace.
- Streaming messages, reasoning, tool progress, and errors now retain their
  canonical state under UI backpressure. Logs and rendered history have explicit
  byte budgets so a noisy process cannot make the TUI grow without bound.
- Cancelling a pending native attach safely releases a late reservation, and
  model discovery no longer repeatedly blocks the UI while catalog data is
  loading.

## Distribution and release integrity

- macOS assets are Developer ID signed and notarized when credentials are
  configured; this release is intentionally unsigned and unnotarized, while
  retaining checksums and GitHub artifact attestations. Linux archives are
  checked for their glibc 2.28 baseline and bundled SQLite before publication.
- GitHub Release assets are uploaded in platform groups: macOS, GNU/Linux and
  Debian packages, then Windows ZIP and Setup. `SHA256SUMS` uses that same
  deterministic order.
- New releases include `amd64` and `arm64` Debian packages after installation,
  execution, and removal smoke tests on Debian 12 and Ubuntu 24.04.

  穿越，不再跟随到选定工作区之外。

  字节上限，避免高噪声进程拖慢终端。
- 原生 attach 可以安全取消；模型目录加载不再反复阻塞 UI。
- 配置 macOS 凭据时会进行 Developer ID 签名和公证；本版本按授权以未签名、未公证
  的形式发布，但仍提供校验和和 GitHub artifact attestation。发布资产按 macOS、
  Linux/Debian、Windows 分组上传，并新增 Debian 12 和 Ubuntu 24.04 验证过的
  `amd64` / `arm64` `.deb` 包。

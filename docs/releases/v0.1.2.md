# Asterline v0.1.2

This release focuses on making native agent CLIs feel at home inside Asterline.

## Highlights

- Added targeted agent-skill completion and native command pass-through after
  prefixes such as `@codex /`.
- Preserved richer native CLI output, including structured tool-call results,
  reasoning, command output, and file-change details.
- Added per-chat `/mode` selection with normal, review, plan, brainstorm, and
  team modes; `/new` returns to normal mode.
- Brainstorm now preserves the submitted topic in chat, runs judgment-free
  seed/build/stretch waves into an append-only IdeaSet, collects independent
  private ballots, aggregates them with Borda scoring, and synthesizes a ranked
  recommendation. A deployment-local `asterline-brainstorm` skill defines
  structured idea cards and can be customized without being overwritten.
- Grok now runs through its ACP stdio server so thought chunks, tool lifecycle,
  diffs, permissions, and sessions are preserved instead of relying on the
  text-only headless event subset.
- Agy now uses its native `stream-json` print output, including response
  deltas, tool lifecycle, result status, and conversation IDs. The adapter uses
  the authoritative final response to repair replacement characters introduced
  by malformed incremental UTF-8 chunks.
- Added policy-driven approval gates for user dispatches, agent relays, and mode
  dispatches.
- Improved session continuity: fresh sessions are created once and pinned,
  explicit session IDs can be resumed, and `/team` now provides an internal
  Codex/Claude/Grok session table limited to the member's working directory.
- Reworked Team text editing with a focused input box, Unicode-safe cursor
  movement, shell-style editing shortcuts, atomic paste, and real cancel
  semantics.
- Joined model and reasoning-effort selection in the Team model picker:
  `↑`/`↓` selects a model, `←`/`→` selects a supported effort, and `Enter`
  persists both. Detected models and default efforts are shown directly;
  `default` remains only as the no-model fallback and for unset session values.
- Improved terminal interaction: mouse text selection and clipboard copy,
  including the header/footer status bars; atomic bracketed paste, faster wheel
  scrolling, prompt history on arrow keys, bounded selection inside drawers,
  and `Esc` interruption behavior.
- Updated the team skill protocol so the visible roster only advertises
  available teammates and no longer implies automatic delegation.

## 中文更新摘要

- 支持在 `@codex /` 等成员前缀后补全并透传 Agent CLI 自带的 Skill 命令。
- 更完整地展示原生 CLI 工具调用、推理、命令输出和文件修改结果。
- 新增对话内持久的 `/mode` 选择，包含正常、审查、规划、头脑风暴和团队模式；
  `/new` 会恢复 normal 模式。
- 头脑风暴输入会保留在聊天记录中，并以“播种→构建→拓展”多轮无评判生成汇入只追加
  IdeaSet。
- Grok 改用 ACP stdio 服务，完整保留思考片段、工具生命周期、diff、权限请求和会话。
- Agy 改用原生 print `stream-json`，保留回复增量、工具状态、最终结果和会话 ID。
- 审批策略覆盖用户消息、Agent 中继和模式派发。
- 改进会话连续性，并在 `/team` 内提供仅限成员当前目录的会话选择表格。
- Team 字段使用独立编辑框，支持 Unicode 光标、Shell 风格快捷键和秒粘贴。
- Team 模型列表现在用 `↑`/`↓` 选择模型、`←`/`→` 选择 effort，按 `Enter` 同时保存；
  未显式设置的模型、effort 和会话统一显示为 `default`。
- 改进鼠标复制（含顶部和底部状态栏）、滚轮滚动、上下历史消息、Drawer 选择边界和
  `Esc` 打断。
- Team Skill 名单现在仅表示可用成员，不再默认触发不必要的 Agent 消息。

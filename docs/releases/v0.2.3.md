# Asterline v0.2.3

Asterline v0.2.3 adds native installers, strengthens persistence guarantees,
and makes the project easier to evaluate and install on every supported
platform.

## Highlights

- Added a universal macOS DMG containing a native Installer package for both
  Apple silicon and Intel Macs. The Release workflow mounts the image, expands
  its package payload, verifies both architectures, and executes the packaged
  CLI before publication.
- Added a per-user Windows Setup executable with `Path` registration, a standard
  uninstaller, installer smoke tests, and checksum-verified automatic updates.
- Reorganized the English and Chinese project pages around product value,
  installation, first use, core workflows, and safety boundaries. Detailed
  platform procedures now live in dedicated installation guides.

## Reliability and security

- Made run completion, blocking, verification, and recovery fail closed when a
  required state transition cannot be persisted. Queued work no longer starts
  after a failed terminal-state write.
- Prevented agent control envelopes and routes from executing when their
  canonical message or route could not be saved.
- Added an exclusive store lock so two Asterline processes cannot concurrently
  own the same SQLite database.
- Bounded each model response to 64 executable control envelopes while keeping
  excess lines visible for diagnosis.
- Sent Agy prompts over standard input instead of process arguments, and made
  read-only or sandboxed execution override permission-bypass settings.
- Made Claude settings discovery use the cross-platform user-home resolver.
- Added dependency auditing to regular CI and the Release quality gate, while
  reducing Syntect to the features Asterline actually uses.

## Distribution

- Release assets now include Linux archives, portable macOS archives, a
  universal macOS DMG, a portable Windows ZIP, and a Windows Setup executable.
- `SHA256SUMS` and GitHub artifact attestations cover every archive and
  installer.
- The macOS workflow supports Developer ID application and installer signing,
  notarization with `notarytool`, and ticket stapling when repository
  credentials are configured.
- Release publication remains gated by Linux, macOS, and Windows tests.

## 中文摘要

- 新增同时支持 Apple silicon 与 Intel 的通用 macOS DMG，内含原生 PKG
  安装器；发布流程会挂载镜像、展开安装载荷、检查双架构并实际运行其中的 CLI。
- 新增 Windows 当前用户安装器、`Path` 注册、标准卸载入口、安装 smoke test，
  以及基于 `SHA256SUMS` 校验的自动更新。
- 运行完成、阻塞、验证和恢复状态改为持久化失败即停止，不会在终态写入失败后继续
  派发队列任务。
- Agent 消息或路由保存失败时，不再执行其中的控制信封；单次模型响应最多执行 64
  条控制信封，超出内容仍会保留显示。
- 同一 SQLite 状态库现在只能由一个 Asterline 进程持有。
- Agy 提示改由标准输入传递；只读与沙箱策略不会再被权限绕过设置覆盖。
- 中英文首页重新按产品定位、安装、首次使用、核心工作流与安全边界组织，平台细节
  移入独立安装指南。
- 常规 CI 与 Release 均加入依赖安全审计；所有发布包与安装器都生成校验和及构建
  来源证明。

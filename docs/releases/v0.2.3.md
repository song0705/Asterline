# Asterline v0.2.3

Asterline v0.2.3 completes the cross-platform CI hotfix started in v0.2.2.

## Fix

- Normalize CRLF line endings before extracting the fenced Team JSON example
  in documentation tests. The Windows library suite was already green in
  v0.2.2; this fixes the remaining Windows-only documentation-test failure.

## 中文摘要

- 文档测试在提取 Team JSON 示例前会先规范化 CRLF 换行。`v0.2.2` 的 Windows
  库测试已经全部通过，本修复解决最后一个仅出现在 Windows 的文档测试失败。

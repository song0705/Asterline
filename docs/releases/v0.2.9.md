# Asterline v0.2.9

[English](v0.2.9.en.md)

> 这一版把日常终端用起来：全屏接管、滚轮翻聊天、拖选复制，以及重新打开后
> 继续上次对话。原生会话也更老实——Claude 的工具不再跑到最终回复后面，Codex
> 的思考和收尾文本不会再丢，Team 里的模型目录可以随时按 `t` 重拉。

---

## 重点内容：你现在可以

- 在全屏界面里用滚轮翻聊天、用上下键翻输入历史，并拖选复制。选中高亮是中性灰，
  不再整行铺亮蓝。退出后回到原来的终端。
- 重新打开 Asterline 时继续当前对话。只有 `/new` 或 `/clear` 会开始新会话；
  两者现在是同一条命令。
- 看 Claude 时默认只显示“思考了多久”，按 `Ctrl+T` 再展开正文。工具调用会出现在
  最终回复之前。
- 在 `/team` 的 **model** 上按 `t` 随时重拉该后端目录。启动时会扫描四个已安装
  CLI，而不是等到你添加成员才开始。
- 在官方 Codex / Claude 的 resume 列表里认出 `Asterline · 成员名`。项目目录搬家
  后，保存在 `.asterline/team.json` 里的旧 workspace 会跟着当前打开的目录纠正。

## 概览

Asterline v0.2.9 是一次以终端手感和会话连续性为主的维护版本。主界面回到全屏
备用屏幕：顶栏固定在上、聊天在中间、输入在底部。鼠标滚轮滚动聊天，不再被当成
方向键去翻旧输入。拖选通过 OSC 52 写入剪贴板。

Claude 的思维链默认折叠；Codex App Server 在缺少 `item/completed` 时仍会保留已
流出的文本。协作模式里发给具体成员的 `@member` 消息不再被当成第二轮编排任务。

本版没有数据库 schema 迁移。现有 team 文件继续兼容。

---

## 新功能

### 全屏聊天：滚动、复制、顶栏归位

主 TUI 使用备用屏幕，不再把 `cargo run` 或 `ls` 留在聊天中间。滚轮滚动聊天或
打开的抽屉；上下键仍只回忆输入历史。拖选复制只高亮真正选中的文字，底色为中性
zinc 灰。

### 重新打开即继续；`/clear` 等于 `/new`

默认复用上次选中的对话、成员和后端会话。`/new` 与 `/clear` 都会清空当前会话并
创建新的后端 session ID。进行中的成员或协作运行仍会拒绝这次重置。

### Team：启动时扫齐模型，`t` 随时重拉

四个已安装 CLI 的模型目录在启动时各扫一遍，结果按后端和工作目录共享。焦点在
**model** 时按 `t` 会重新拉取，不论上次成功还是失败；进行中的同一请求不会重复
启动。

---

## 交互调整

- Claude 思考默认折叠为耗时提示，`Ctrl+T` / `Ctrl+O` / `Ctrl+G` 展开详细输出。
- Codex 原生 thread 会被标成 `Asterline · <成员名>`，方便在官方 resume 列表里辨认。
- 协作运行期间，发给单个成员的消息按普通一对一路由处理。
- 流式回复如果只收到 delta、没有最终文本字段，不会被空的完成事件清掉。

---

## 升级提醒

### 不要复用 `v0.2.8` tag

`v0.2.8` 已经发布。本版是新的 `v0.2.9`。不要移动或重打旧 tag。

### 拖选复制走应用剪贴板

全屏接管后，终端不再提供原生选中。松开鼠标后文本写入系统剪贴板（OSC 52）。
VS Code 与纯终端都走同一条路径。
